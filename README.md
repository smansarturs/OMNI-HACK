# OMNI-HACK
This is application game, where user doing some hacking tasks.
These hacking minigames are looking like in GTA 5 and GTA Online during the heists.

If you're done good in each hacking minigame, you earn credits.
And your security level and integrity will increase.
Credit earning after accomplished hacking minigame depends on your security level.
LVL 1 - 100 Credits
