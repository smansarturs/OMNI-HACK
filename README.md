# OMNI-HACK
This is application game, where user doing some hacking tasks. <br>
These hacking minigames are looking like in GTA 5 and GTA Online during the heists.

If you're done good in each hacking minigame, you earn credits. <br>
And your security level and integrity will increase. <br>
Credit earning after accomplished hacking minigame depends on your security level.
